# Off-Campus Quiz

To jest gotowa, uporządkowana wersja quizu w HTML, CSS i JavaScript.

## Co zawiera

- pełne polskie nazewnictwo i zapis,
- 15 bardziej opisowych pytań problemowych,
- lokalne grafiki bohaterek w folderze `assets`,
- statyczną strukturę gotową do GitHub Pages.

## Publikacja na GitHub Pages

1. Utwórz repozytorium na GitHubie.
2. Wgraj pliki `index.html`, `.nojekyll`, `README.md` oraz folder `assets`.
3. W ustawieniach repozytorium włącz GitHub Pages dla gałęzi `main`.
4. Po chwili strona będzie dostępna jako statyczna witryna.
